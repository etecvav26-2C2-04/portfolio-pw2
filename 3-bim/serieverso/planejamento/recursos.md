# 🧩 Recursos que o Site Utiliza — SérieVerso

- **Formulário de contato** (`pages/contato.php`), com validação básica de campos obrigatórios;
- **Catálogo com busca/filtro por gênero** na página de séries;
- **Menu responsivo** (navbar colapsável do Bootstrap 5), com seletor de idioma;
- **Sistema de login** para a área administrativa (`admin/`), com sessão PHP;
- **CRUD completo de séries** (criar, listar, editar, excluir) usando PHP + PDO + MySQL;
- **Internacionalização** (pt-br, en-us, es) através de arquivos de idioma em `lang/`;
- **Selo de avaliação** (nota estilo IMDb) destacado visualmente em cada card de série.

## Recursos planejados para versões futuras
- Galeria de imagens/trailers por série;
- Gráfico simples com a distribuição de séries por gênero no painel administrativo;
- Integração com uma API pública de dados de filmes/séries para atualização automática do catálogo.
