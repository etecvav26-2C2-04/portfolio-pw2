# 🎬 SérieVerso

Projeto didático de desenvolvimento web utilizando:

- HTML5
- CSS3
- Bootstrap 5
- PHP
- MySQL
- Git/GitHub

O projeto simula o desenvolvimento de um sistema web real para um catálogo fictício de séries de TV chamado **SérieVerso**.

---

## 🎯 Objetivos do Projeto

O sistema será utilizado inicialmente para:

- divulgação do catálogo de séries;
- apresentação das séries (sinopse, gênero, ano, nota e temporadas);
- página institucional (Sobre) e formulário de contato;
- controle interno do catálogo (cadastro, edição e remoção de séries);
- gerenciamento administrativo básico (login e painel do administrador).

Futuramente:

- sistema de avaliações dos próprios usuários;
- autenticação de usuários comuns (não apenas administradores);
- listas personalizadas ("Minha lista");
- dashboard administrativo com estatísticas;
- integração com API pública de dados de filmes/séries.

## 📂 Estrutura do Projeto

```text
serieverso/
├── assets/         → CSS, imagens do site e uploads
├── includes/       → cabeçalho, rodapé, menu, autenticação
├── pages/          → páginas públicas do site
├── admin/          → área administrativa (login + CRUD de séries)
├── database/       → script SQL do banco de dados
├── config/         → configurações (URL base, conexão com banco)
├── lang/           → arquivos de idioma (pt-br, en-us, es)
├── logo/           → logotipo do projeto
├── imagens/        → pôsteres de exemplo do catálogo
├── planejamento/    → documentação didática do planejamento
├── referencias/     → fontes de dados e referências usadas
└── index.php        → página inicial (Home)
```

Documentação completa: [`planejamento/`](planejamento/) e [`referencias/`](referencias/)
